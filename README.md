# Not Enough Animations

A native Horizon mod by **CayMac** that brings essential third-person player animations to Horizon:

- **Eating & Drinking**: Smoothly lifts food, potions, milk, and stews directly to your mouth with natural chewing motions and subtle head nodding.
- **Two-Handed Map Holding**: Realistically holds maps with both hands in front of the chest while reading, complete with gentle breathing motion.
- **Ladder & Vine Climbing**: Displays authentic hand-over-hand climbing animations and stepping leg motions while scaling ladders, vines, and scaffolding.
- **Boat Rowing**: Synchronizes arm rowing movements with the boat's oars while steering across water.
- **Full In-Game Configuration**: Every animation can be toggled individually in `Options > Mods > Not Enough Animations`.
- **Zero Impact on Vanilla Mechanics**: Purely visual animations that never alter server mechanics, hitboxes, combat timings, or movement speed.
